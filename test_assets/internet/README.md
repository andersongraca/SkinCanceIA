# Imagens dermatológicas encontradas na internet

As imagens `isic_reference_01.jpg` e `isic_reference_02.jpg` foram obtidas de resultados visuais associados à página oficial do ISIC Archive: https://www.isic-archive.com/.

A busca não preservou o identificador individual da imagem nem os termos específicos da coleção. Portanto, estes arquivos são referências visuais para inspeção e não devem ser usados como dados de treinamento, como evidência clínica ou publicados como se tivessem licença individual confirmada. Para uso científico, substituir por imagens baixadas pelo fluxo oficial do ISIC com identificador e licença registrados.
